# 群星使用指南

群星是一个 Windows 桌面程序。它把你电脑上已经装好、已经登录的 AI 编程工具派去做开放数学问题：
- 每一步都能看到；
- 随时能暂停、插话、追加预算；
- 证明可以交给 Lean 检查。

这份指南对应第一个测试版。界面和指南不一致时，以界面为准，也欢迎[开 Issue](https://github.com/qunxingmath-org/qunxing-app/issues) 告诉我们。

## 三句话说明白

- **群星本身免费**。AI 的花费走你自己的订阅或 API：
  - 每道题开跑前设预算，到顶会停下来问你；
  - 另外还有每日花费上限。
- **默认不上传任何东西**。运行记录、证明和花费都存在你的电脑上。
- **点亮一颗星**要两样都过：
  - Lean 在你电脑上编译通过；
  - 题意复核确认 Lean 里证明的就是原题。
