# 常见问题

## 安装和启动

### Windows 提示"Windows 已保护你的电脑"

确认文件是从本仓库的 Release 或群星网站下载的，然后点 **更多信息** → **仍要运行**。
- 想核对文件，见[安装](install.md#核对文件可选)。

### 窗口右上角显示"正在重连…"

群星的界面和后台之间的推送断了。
- 它会自动重连，连上后补上漏掉的事件，一般不用管。
- 一直连不上：关掉群星，重新打开。

### 窗口右上角显示"连接已失效"

后台不再接受这个窗口。关掉窗口，重新打开群星。

### GitHub 下载很慢

用[网站下载页](https://www.qunxingmath.org/download/)上的国内镜像，文件和 GitHub 上的一样。

## 连接 Agent

### 新手引导找不到我的 Agent

1. **先在终端里确认它能用**：运行 `codex`、`claude` 或 `gemini`，能正常对话，并且已经登录。
2. **在新手引导里点 重新查找**。
3. **还是找不到**：
   - 换了安装位置的，确认它在系统的 PATH 里：在新开的终端里直接输入命令能运行，才算在 PATH 里；
   - 重启群星再试；
   - 仍不行，请[开 Issue](https://github.com/qunxingmath-org/qunxing-app/issues)，写上你的 Windows 版本、Agent 的名字和版本。

### 卡片上写"缺 ACP 适配器"

Codex CLI 和 Claude Code 要一个小的转接程序（ACP 适配器）才能接进群星。Gemini CLI 不需要。
- 点卡片上的 **安装适配器**，看完说明后点 **确认安装**。
- 适配器从 npm 下载，装在群星自己的目录里，不改你的全局配置。

**装不上的话**：
- 多半是连不上 npm，换个网络再试；
- 把出错信息（去掉里面的个人信息）贴到 Issue 里。

### 测试连接失败

- **确认已经登录**：在终端里打开这个 Agent，看它能不能正常回答。
- **用订阅的**：看看订阅额度是不是用完了。
- **用 API 的**：看看 API 密钥和余额。
  - 密钥是在 Agent 自己那里设置的，群星不经手。

### 指挥台是什么，一定要用吗

指挥台是你自己的 Agent，开在群星窗口里，可以帮你找题、开题、盯着运行。
- 不用也行：抽题、开题、运行都能自己点。
- 指挥台做的任何公开提交，都要你亲手确认。
- 它的开销单独记在"主控"账本里。

## 花费

### 会花多少钱

群星本身免费。AI 的花费按你自己的订阅或 API 计算。

**用订阅**：
- 不另外花钱，用的是你的会员额度；
- 界面上的金额是按 API 价格折算的参考值。

**用 API**：按用量付费，每一笔都记进账本。

**三道闸**：
- 每道题开跑前，分别设解题和验证的预算，到顶会停下来问你；
- 每日花费上限：到了就不再开新的运行；
- 查新单独记账，不占解题预算。

### 订阅额度用完了

群星会等到额度恢复的时间，自动继续。等待的时间不算进耗时。
- 不想等：在"谁来解题"里把这个环节换成 API。
- 设置里重新进行新手引导，就能回到"谁来解题"这一步。

### 预算到顶了

见[跑第一道题](first-problem.md#预算到顶)。三个选择：
- 追加预算；
- 带着现有进展去做 Lean 检查；
- 收工。

## 运行中

### AI 在等我批准，但我没看到窗口

- 看任务栏：群星的图标会闪，也会有系统通知。
- 运行页右上角会显示"等你回答"。
- 想让窗口直接弹到最前面：设置 → **需要我批准时，把群星窗口弹到最前面**。
- 嫌问得太多：设置 → **运行方式**，改成"关键处问我"或"一键全自动"。

### 插话、追加预算以后，结果还算数吗

算。只是这次运行会被标成"有干预"或"有人工提示"，统计时和没插手的分开比较。

### 停下以后还能接着做吗

能。点了 **到此为止** 的，结果页上有 **继续** 按钮，从停下的那一步接着做。

## 结果

### "点亮"是什么意思，结果可信吗

点亮要两样都过：
- Lean 在你的电脑上编译通过，只用了标准公理；
- 题意复核确认 Lean 里证明的就是原题。

点亮依据的是你本机的检查结果。群星不做人工验证，也不为结果担责。

证明提交以后，群星会在公开仓库的 CI 里重跑 Lean。通过后，星上加"Lean 已复跑"的记号。

### Lean 检查很慢

第一次检查要下载 Mathlib 的缓存，比较慢。之后就快了。见 [Lean](lean.md)。

### 题库更新失败

- 新题库检查不通过时，群星会保留旧版，不影响使用。
- 过一会儿再试；网络不好时，GitHub 可能连不上。

## 数据和隐私

### 我的数据存在哪里

默认在 `C:\Users\你的用户名\Qunxing`，每次运行一个文件夹。见[卸载与数据位置](uninstall.md)。

### 能不联网用吗

设置里打开 **只在本地运行**：不收更新、不上传，题库停在当前版本。
- 但调用 AI 仍然要联网，因为 AI 工具本身要联网。
- 见[隐私与上传](privacy-and-uploads.md)。

### 群星会上传我的对话吗

不会。默认什么都不上传。上传开放以后，也只有你点了才传，而且对话原文、提示词永远不在上传内容里。

## 反馈

### 怎么报告问题

[开 Issue](https://github.com/qunxingmath-org/qunxing-app/issues)，写上：
- 群星的版本、Windows 版本；
- 做了什么、看到了什么、本来想看到什么；
- 截图。

**截图前**，把 API 密钥、令牌、你的用户名和不想公开的路径遮住。

**安全问题**不要公开发，见 [SECURITY.md](../../../SECURITY.md)。
