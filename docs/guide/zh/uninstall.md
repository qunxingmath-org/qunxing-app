# 卸载与数据位置

## 数据存在哪里

**都在你选的数据文件夹里**：
- 默认是 `C:\Users\你的用户名\Qunxing`；
- 在设置的 **数据文件夹** 里能看到实际位置，可以 **复制路径**；
- 也可以点 **更改…** 换一个，已有的文件会一起搬过去。

**每跑一次，就多一个文件夹**：按题号整理，再按运行时间分开：

```text
C:\Users\你的用户名\Qunxing\runs\<题号>\<运行时间>\
```

**里面有**：
- `run.json`：运行记录和用量；
- `proof.md`：自然语言证明；
- `lean\`：Lean 题面、证明和本机检查结果；
- `verdicts\`：题意复核等结论；
- `novelty\`：查新报告；
- `originals\`：会话原件的副本；
- `failure-path.md`：失败路径摘要（写了才有）。

**找某道题的文件**：
- 结果页的"本地文件"一栏，点 **在文件夹中显示**；
- 星图里点那颗星，右边详情里有本机文件的位置；
- 文件夹按题号命名，用 Windows 自带的搜索也能找到。

**数据文件夹里还有**：题库快照、你的研究计划，以及一个本机索引（星图靠它找到每道题的文件）。

## 卸载群星

- **安装版**：Windows 设置 → **应用** → **已安装的应用**，找到"群星"，点右边的 **…** → **卸载**。
  - Windows 10 是：设置 → 应用 → 应用和功能 → 群星 → 卸载。
- **免安装版**：直接删掉解压出来的文件夹。

**卸载不会删除数据文件夹**。你的运行记录和证明都还在。不需要的话，请自己删除。

## 群星以外的东西

下面这些是你自己装的，卸载群星不会动它们。要卸载，按各自的说明做：
- **AI 工具**：Codex CLI、Claude Code、Gemini CLI。
- **Lean**：在终端里运行 `elan self uninstall`，会删掉 elan 和它装的所有 Lean 版本。
- **WebView2 运行库**：它是 Windows 的组件，别的程序也在用，一般不要卸载。
